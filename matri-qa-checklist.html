How to run this checklist

  1. Create two test accounts — one fresh (no data) to test empty states, one fully populated to test data flows. Do not use your own account.
  2. Test on both platforms — web (Chrome desktop) and Android device. Some sections are Android-only.
  3. Use Android Logcat filtered on mtri.app or authFetch to catch silent JS errors during Android testing.
  4. AI context tests — wait ~60 seconds after data changes before verifying AI personalisation, or manually trigger a health context refresh.
  5. Mark each item ✓ Pass, ✗ Fail, or — Skip. Note the build version and date tested.
  6. For prescription tests — use the test files in the qa-test-files/ folder. Open in Chrome → Print → Save as PDF, then upload that PDF to the app.
📁 Test Files Guide
All test files are in the qa-test-files/ folder. Open each HTML file in Chrome → Cmd+P → Save as PDF → upload to the app. Each file has a coloured tag in the top-right corner identifying its code (P1, L1, etc.). Yellow notes inside each file explain what to verify — these notes are hidden when printing.
